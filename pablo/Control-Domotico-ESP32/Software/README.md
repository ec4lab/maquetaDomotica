## 💻 5. Programación e integración con Home Assistant

En este apartado se documentará la configuración del firmware, la lógica de control de las teclas, la gestión de los estados de las luces y la integración con Home Assistant mediante ESPHome.

Se incluirán los siguientes aspectos:

- Configuración del ESP32 y conexión a la red Wi-Fi.
- Definición de las entradas y salidas GPIO.
- Lectura de las teclas físicas y detección de sus pulsaciones.
- Inversión del estado de cada luz al presionar la tecla correspondiente.
- Control individual de las seis luces desde Home Assistant.
- Sincronización de los estados entre el control físico y la interfaz de domótica.
